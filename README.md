# LetsGO - Visit Planner and Information System
University of Moratuwa • ITE2953 Software Engineering Project

## 🚀 Running on Local Computer:

### 1. Start Backend:
```bash
cd server
npm install
node seed.js
npm run dev
# Running on http://localhost:5000
```

### 2. Start Frontend:
In a new terminal window:
```bash
cd client
npm install
npm run dev
# Running on http://localhost:5173
```
